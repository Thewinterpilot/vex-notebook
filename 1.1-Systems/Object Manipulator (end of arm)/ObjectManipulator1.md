#winter #object-manipulation
# object manipulator base note
# design requirements:
- be able to flip pieces over
- fit on the end of the arm
# idea proposals:
- 180 degree rotating claw
- rollers
- new zealand intake

# decision:
180 degree rotating modified NZ intake

# reasoning:
any claw would be harder to grab multiple game objects with,
a normal NZ intake would not pick things up well,
rollers are just nonvisable for this game
